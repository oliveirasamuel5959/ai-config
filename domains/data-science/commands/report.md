---
description: Turn an analysis into a decision-ready stakeholder report (What / So What / Now What).
argument-hint: "[the analysis or question to report on]"
---

Write the report for: **$ARGUMENTS**

Follow the `data-analyst-reporting` skill.

1. **Name the decision** this informs and who makes it. If no answer changes anything, say so.
2. **State the question** as a testable hypothesis with a metric, population, comparison and
   threshold.
3. **Check the comparison** is fair — a baseline or control group, with the confounders you cannot
   rule out named explicitly.
4. **Quantify honestly** — report an **interval**, not just a point estimate; state n and the time
   window; size any opportunity as a **range** with its most sensitive assumption named.
5. **Structure it What / So What / Now What** — lead with the answer; put methodology after.
6. **Make it auditable** — store the query or notebook alongside, define every term ("active",
   "churn"), and list the assumptions and limitations.
7. **Present it** — one chart per claim, titled with the finding, with n and error bars on it.

Do not present a point estimate as fact, and do not imply causation from a correlation.
